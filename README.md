# Department of Computer Engineering — SAKEC Portal

A modern, responsive, and comprehensive academic portal designed and deployed for the **Department of Computer Engineering** at **Shah & Anchor Kutchhi Engineering College (SAKEC)**, Mumbai.

Deployed on **GitHub Pages**.

---

## 🌟 Key Features

1. **Department Overview & Leadership**:
   - Accreditations: NBA Accredited, NAAC 'A' Grade, Affiliated to University of Mumbai, Approved by AICTE.
   - Head of Department (HOD) welcome address by Dr. Uday Bhave.
   - Formal Vision, Mission, Program Educational Objectives (PEOs), and Program Specific Outcomes (PSOs).

2. **Faculty Members Directory**:
   - Filter faculty by designations: *Professors*, *Associate Professors*, *Assistant Professors*.
   - Real-time search by faculty name, qualification, or research domain.
   - Detailed modal profiles highlighting qualifications, experience, research areas, courses taught, and publications.

3. **State-of-the-Art Laboratories (8 Labs)**:
   - Advanced AI & Deep Learning Research Lab (Lab 401 - NVIDIA RTX GPUs)
   - Cloud Computing & DevOps Lab (Lab 402 - VMware & K3s)
   - Cybersecurity & Digital Forensics Lab (Lab 403 - Isolated Network Sandbox)
   - IoT & Embedded Systems Innovation Lab (Lab 404 - Raspberry Pi & ESP32 Kits)
   - Big Data & Database Engineering Lab (Lab 405 - Hadoop & Spark)
   - Software Engineering & Full-Stack Lab (Lab 406)
   - Computer Networks & Systems Lab (Lab 407 - Cisco Hardware Routers)
   - Computer Graphics & Media Computing Lab (Lab 408 - Unity & Blender)

4. **Curriculum & Syllabus (Rev-2019 'C' Scheme / NEP 2020 Aligned)**:
   - Interactive semester-wise navigator (Semesters III through VIII).
   - Structured tabular view: Course Code, Course Title, Course Type (Theory, Practical, Skill Lab, Project, Elective), Teaching Hours, and Credits.
   - Modal inspection for module breakdown and recommended reference textbooks.
   - One-click **Print / Save PDF** formatted syllabus generator.

5. **Department Achievements & Accolades**:
   - Smart India Hackathon (SIH) National 1st Prize Winners (₹1,00,000 cash prize).
   - IEEE International Conference Best Paper Awards.
   - Government of India published patents in IoT and computer vision.
   - CSI National Best Student Chapter Award.
   - AICTE research funding grants.

6. **Placement Statistics & Interactive Visualizations (Chart.js)**:
   - 5-Year Year-over-Year trend chart comparing Highest Package, Average CTC, and Placement Rate %.
   - Package distribution doughnut chart (Super Dream ₹12+ LPA, Dream ₹8-12 LPA, Core Prime ₹5-8 LPA).
   - Sector-wise recruitment breakdown bar chart.
   - Infinite animated marquee of top recruiters (Amazon AWS, Morgan Stanley, J.P. Morgan, Barclays, LTI Mindtree, TCS, etc.).
   - Placed alumni testimonials.

7. **Notices & Communication Desk**:
   - Live departmental announcements and exam circulars with status tags.
   - Department contact details, campus address, and interactive enquiry form.
   - Dark Mode / Light Mode toggle with persistence.

---

## 🛠️ Technology Stack

- **HTML5 & CSS3**: Modern semantic structure, CSS Variables, Flexbox, Grid, Glassmorphism, Print media queries.
- **JavaScript (ES6+)**: Dynamic dataset rendering, filtering, search, modal management.
- **Chart.js (v4.4.3)**: High-performance canvas data visualization.
- **FontAwesome 6 & Google Fonts (Plus Jakarta Sans, Space Grotesk)**: Modern typography and iconography.
- **GitHub Pages**: Static site hosting with HTTPS and CI/CD deployment.

## 🚀 Local Development

To run locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/TanmayNileshShinde/CollegeDepartmentWebsite.git
   cd CollegeDepartmentWebsite
   ```
2. Open `index.html` directly in any web browser, or serve using Python:
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
